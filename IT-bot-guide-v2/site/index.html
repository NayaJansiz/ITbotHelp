📚 حلّ أسئلة المحاضرة مع Claude

اختر المادة، نزّل ملفاً واحداً فيه كل محاضراتها وكل أسئلتها، أعطه لـ Claude، ثم الصق الرد هنا. الصفحة تتحقق من كل جواب تلقائياً قبل أن ترسله.

قاعدة واحدة: الجواب يُقبل فقط إذا وُجد اقتباسه حرفياً في المحاضرة. إن لم يجد Claude الجواب في المحاضرة يكتب «لم يوجد» وهذا طبيعي.
افتح محادثة جديدة لكل ملف (Claude لا يتذكر المحادثات السابقة). إن ظهر أكثر من جزء فالصق ردود كل الأجزاء معاً في الخطوة ③.

⚡ الطريقة السريعة: ارفع ملفاتك

التحويل يتم على جهازك. لا يُرسل شيء إلى أي مكان قبل أن تفتح Pull Request.

من Telegram Desktop: ⋮ ← Export chat history ← Format = HTML، ودون الصور. بلا ملف تصدير: تُحَل كل أسئلة المادة الموجودة.

① نزّل كل شيء لـ Claude

② افتح Claude (محادثة جديدة)، أرفق الملف، والصق هذه الرسالة:

اقرأ الملف المرفق كاملاً، ثم نفّذ تعليمات المهمة المكتوبة في أوّله. أجب بأسطر JSON فقط: سطر واحد لكل سؤال، بنفس ترتيب الأسئلة، بلا أي كلام آخر وبلا صناديق كود. لا تحذف أي سؤال: إن لم تجد جوابه في المحاضرات فاكتب له NOT-FOUND.
فتح Claude ↗

إن انقطع الرد قبل نهاية الأسئلة اكتب له: «أكمل» ثم الصق كل الأسطر معاً.

③ الصق رد Claude

مراجعة وتعديل (اختياري)

راجع أولاً ما ليس «موثّقاً». يمكنك تعديل الجواب أو الشرح. تغيير الجواب بدون اقتباس صحيح من المحاضرة يُسجَّل «جواب طالب» ويقرّره المشرفون عند الدمج. تعديلاتك محفوظة في المتصفح.

④ أرسل الملف للمراجعة

حروف إنجليزية وأرقام فقط، من رابط صفحتك: github.com/USERNAME

أ) Fork للمستودع (مرة واحدة) ب) رفع الملف إلى نسختك ج) فتح Pull Request

عندك محاضرة PDF جديدة لهذه المادة؟

ارفع الملف إلى مجلد inbox/رقم المادة/ في نسختك (بعد الـ Fork) ثم افتح Pull Request. بعد أن يدمجه المشرف يتحوّل الملف تلقائياً إلى نص وتظهر المحاضرة في هذه الصفحة.

رفع ملف PDF إلى نسختك
الخطوات بإيجاز:
  1. الأسرع: اختر المادة ثم ارفع PDF المحاضرة وتصدير تيليجرام في بطاقة ⚡، ونزّل الملف وأعطه لـ Claude. (أو اختر محاضرات الموقع الجاهزة.)
  2. الصق الرد واضغط «تحقّق»: ✓ يعني الاقتباس موجود في المحاضرة.
  3. نزّل الـ zip (أو ملف الرد في الطريقة العادية) وارفعه إلى نسختك (Fork).
  4. افتح Pull Request. المشرف يراجع ويدمج.
  5. لا تعدّل ملفاً موجوداً: أضف ملفك الجديد فقط (الرد والملخص، أو ملف PDF في inbox/).
للمشرفين: كيف تُنشأ الحزم؟

تُشغَّل على حاسوب المشرف، لا في المتصفح. تحتاج pip install pymupdf beautifulsoup4.
